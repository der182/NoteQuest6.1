# October 12 UI redesign

Based on the user-provided Designer-2.png mockup and the subsequent agreed changes. The mockup is a visual reference; it does not add instructions or imaginary student progress data.

- [x] Original pin/note/star Note Quest SVG logo; navy-to-blue header, rounded cards, pale backgrounds, blue selection accents.
- [x] Home / Practice / References / Advanced Setup navigation. No Teacher/Director Tools labels, dashboard, or achievements.
- [x] Real licensed instrument photographs for all 13 families, bundled offline with source/creator/license credits.
- [x] Home equipment options: F single/double horn, trombone trigger, 3/4 valves for euphonium and tuba, euphonium notation.
- [x] Beginner / Intermediate / Advanced / Custom student level cards. Beginner uses five concert B-flat scale notes, horn F optional; Intermediate adds a broader chromatic range; Advanced covers the full verified data; Custom opens Advanced Setup.
- [x] Practice mode cards: Multiple Choice / Build the Combination, exclusively.
- [x] Native Questions dropdown: default 10, options 20/30, visible arrow. Question rounds remain the default; timed options stay available in Advanced Setup.
- [x] Desktop notation-left/response-right workspace; Multiple Choice 2×2 answer cards; responsive phone presentation and compact desktop chart.
- [x] Advanced Setup sidebar and topic pages retain every detailed exercise control. Floating animated sheets remain usable during play.
- [x] Header Appearance & Sound gear; device preferences persist. Appearance/guide modals pause play without resetting the round.
- [x] References browses notes, primary/alternate charts, tone playback, guide, sources, and photograph credits.
- [x] Shared/imported customized settings land on Practice without being replaced by a beginner preset.
- [x] Existing musical data, chart artwork, alternate checking, drag painting, shortcuts, tones, scoring, missed practice, timing, and sharing retained.
- [x] Fix the horn concert-F choice carrying into another instrument's beginner selection.
- [x] Update documentation and offline HTML/project archive.
